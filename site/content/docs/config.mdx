---
title: nub.jsonc
description: The project file that configures Nub's runtime, dependency installs, and temporary package runs.
---

Put `nub.jsonc` at the project root. Nub finds the nearest file by walking up from the command's working directory.

The file uses JSON with comments and trailing commas. Unknown keys and invalid values stop the command with an error.

## Every field

```jsonc title="nub.jsonc"
{
  "$schema": "https://nubjs.com/schema/latest.json",

  // ── Runtime — applies to file runs, scripts, and watch mode ──
  "preload": ["./instrumentation.ts"],       // modules loaded before the entry file
  "nodeOptions": ["--enable-source-maps"],   // Node options for every run
  "v8Flags": ["--expose-gc"],                // V8 flags, via NODE_OPTIONS
  "envFile": ["./env/base.env", "./env/local.env"], // true | false | path | path[]
  "define": { "APP_VERSION": "\"1.4.0\"" },  // compile-time identifier replacement
  "loader": { ".txt": "text" },              // extension → loader
  "conditions": ["development"],             // extra package export conditions
  "tsconfig": "./tsconfig.runtime.json",     // TypeScript config for the runtime
  "verifyDepsBeforeRun": "warn",             // warn | error | false
  "nodeCompat": false,                       // true = plain Node, version pinning kept

  // ── Installs ──
  "install": {
    "nodeLinker": "symlink",                 // symlink | isolated | hoisted
    "symlinkDisablePattern": ["electron"],   // packages to materialize in the project
    "hoist": false,                          // hidden fallback tree; isolated only
    "minimumReleaseAge": "3d",               // reject versions published too recently
    "minimumReleaseAgeExclude": ["@company/*"],
    "nodeOptions": ["--max-old-space-size=8192"] // for lifecycle scripts
  },

  // ── Temporary package runs ──
  "dlx": {
    "consent": "prompt",                     // prompt | never
    "envFile": "./env/tools.env"             // same forms as the top-level envFile
  }
}
```

Each field has its own section below, and each is also documented on the page for the feature it configures.

## `$schema`

Add the public schema URL for editor completion and validation.

```jsonc title="nub.jsonc"
{
  // ...
  "$schema": "https://nubjs.com/schema/latest.json"
}
```

## Project and global configuration

Use a project `nub.jsonc` for settings that belong to one repository. Use the global file for personal defaults that should apply everywhere:

```text title="Global configuration"
~/.config/nub/nub.jsonc
```

Setting `XDG_CONFIG_HOME` moves it to `$XDG_CONFIG_HOME/nub/nub.jsonc`. On Windows the default is `%APPDATA%\nub\nub.jsonc`.

Project files fail loudly when they contain invalid values. The global file is best-effort: Nub ignores it when it cannot be read or parsed.

More specific settings replace broader ones:

```text
command-line option
  ↓
environment setting
  ↓
project nub.jsonc
  ↓
global nub.jsonc
  ↓
built-in default
```

Relative paths come from the file that supplied the final value. A project `preload` path is relative to the project file; a global `preload` path is relative to the global file.

## Runtime

The top-level fields configure file runs, package scripts, and watch mode.

### `preload`

Load one or more modules before the entry file.

```jsonc title="nub.jsonc"
{
  // ...
  "preload": [
    "./instrumentation.ts",
    "./register-hooks.mjs"
  ]
}
```

Paths are resolved from the directory containing `nub.jsonc`.

```ts title="instrumentation.ts"
globalThis.performance.mark("app-start");
```

An entry may also be a bare package specifier, resolved the way an import in your project would be.

```jsonc title="nub.jsonc"
{
  // ...
  "preload": ["tsx/esm", "@company/telemetry/register"]
}
```

A bare specifier resolves through the package's `exports` map, so [`conditions`](#conditions) steers which file it loads.

```jsonc title="nub.jsonc"
{
  // ...
  "conditions": ["development"],
  "preload": ["@company/telemetry/register"]
}
```

```json title="node_modules/@company/telemetry/package.json"
{
  "exports": {
    "./register": {
      "development": "./register.dev.js",
      "default": "./register.js"
    }
  }
}
```

### `nodeOptions`

Pass Node options to runtime commands.

```jsonc title="nub.jsonc"
{
  // ...
  "nodeOptions": [
    "--enable-source-maps",
    "--stack-trace-limit=50"
  ]
}
```

### `v8Flags`

Pass V8 flags without adding them to every command.

```jsonc title="nub.jsonc"
{
  // ...
  "v8Flags": [
    "--expose-gc"
  ]
}
```

Flags reach Node through `NODE_OPTIONS`, so the accepted set is the one your Node version allows there. Nub checks each entry against that set before Node starts, which turns an unusable flag into a Nub error rather than a Node startup abort.

```text
nub.jsonc `v8Flags` option `--harmony` is not supported by Node 26.5.0
```

### `envFile`

Keep automatic environment-file discovery with `true`.

```jsonc title="nub.jsonc"
{
  // ...
  "envFile": true
}
```

Disable environment-file loading with `false`.

```jsonc title="nub.jsonc"
{
  // ...
  "envFile": false
}
```

Read one exact file instead of the automatic set.

```jsonc title="nub.jsonc"
{
  // ...
  "envFile": "./env/development.env"
}
```

Compose several files in order. Later files replace earlier values.

```jsonc title="nub.jsonc"
{
  // ...
  "envFile": [
    "./env/base.env",
    "./env/development.env",
    "./env/local.env"
  ]
}
```

Paths are resolved from the directory containing `nub.jsonc`, not the shell's current directory.

Paths also expand `${VAR}` and `$VAR` against the environment, which a config file never gets from the shell.

```jsonc title="nub.jsonc"
{
  // ...
  "envFile": "./env/.env.${APP_ENV}"
}
```

```bash
APP_ENV=staging nub app.ts   # reads ./env/.env.staging
```

### `define`

Replace identifiers at compile time. Each value is a JavaScript source string.

```jsonc title="nub.jsonc"
{
  // ...
  "define": {
    "APP_VERSION": "\"1.4.0\"",
    "FEATURE_SEARCH": "true",
    "BUILD_NUMBER": "42"
  }
}
```

```ts title="version.ts"
console.log(APP_VERSION);   // "1.4.0"
console.log(FEATURE_SEARCH); // true
console.log(BUILD_NUMBER);   // 42
```

### `loader`

Choose a loader for a file extension.

```jsonc title="nub.jsonc"
{
  // ...
  "loader": {
    ".txt": "text",
    ".config": "jsonc",
    ".data": "yaml",
    ".component": "tsx"
  }
}
```

The supported loader names are:

```text
text
jsonc
json5
toml
yaml
ts
tsx
jsx
```

### `conditions`

Add package export conditions.

```jsonc title="nub.jsonc"
{
  // ...
  "conditions": [
    "development",
    "react-server"
  ]
}
```

```json title="node_modules/example/package.json"
{
  "exports": {
    ".": {
      "development": "./development.js",
      "default": "./production.js"
    }
  }
}
```

### `tsconfig`

Choose the TypeScript configuration used by Nub's runtime.

```jsonc title="nub.jsonc"
{
  // ...
  "tsconfig": "./tsconfig.runtime.json"
}
```

```jsonc title="tsconfig.runtime.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### `verifyDepsBeforeRun`

Warn when installed dependencies may be stale.

```jsonc title="nub.jsonc"
{
  // ...
  "verifyDepsBeforeRun": "warn"
}
```

Stop instead of running.

```jsonc title="nub.jsonc"
{
  // ...
  "verifyDepsBeforeRun": "error"
}
```

Skip the check.

```jsonc title="nub.jsonc"
{
  // ...
  "verifyDepsBeforeRun": false
}
```

The `"install"` and `"prompt"` values are accepted for pnpm compatibility and currently behave as `"warn"`.

### `nodeCompat`

Use plain Node behavior while keeping Nub's Node version selection.

```jsonc title="nub.jsonc"
{
  // ...
  "nodeCompat": true
}
```

This is the project-wide form of the `--node` escape hatch. Nub does not load its runtime hooks, environment files, preloads, custom loaders, defines, or conditions.

## `install`

The install block configures Nub's package manager and dependency lifecycle scripts.

It applies when Nub is the project's package manager. A project with an `npm`, `pnpm`, `yarn`, or `bun` lockfile keeps that tool's own configuration, and this block is ignored.

### `install.nodeLinker`

Use Nub's shared symlink layout.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "symlink"
  }
}
```

Use a project-local isolated store.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "isolated"
  }
}
```

Use a flat, real-directory layout.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "hoisted"
  }
}
```

The `"pnp"` value is reserved for future Plug'n'Play support. An install that uses it is rejected until support lands.

```text
nub: `install.nodeLinker: "pnp"` is reserved and not supported yet [ERR_NUB_CONFIG_UNSUPPORTED]
```

### `install.symlinkDisablePattern`

Materialize selected packages inside the project instead of linking them from the shared store.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "symlinkDisablePattern": [
      "electron",
      "@company/native-*"
    ]
  }
}
```

### `install.hoist`

Fill the hidden fallback tree that packages reach when they import something they never declared. It applies to the isolated layout only, so set `nodeLinker` alongside it.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "isolated",
    "hoist": true
  }
}
```

Keep the strict layout, where an undeclared import fails.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "isolated",
    "hoist": false
  }
}
```

Hoist only matching packages.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeLinker": "isolated",
    "hoist": [
      "*eslint*",
      "@types/*"
    ]
  }
}
```

Nub rejects the field under any other layout rather than accepting a setting it would ignore.

```text
nub: `install.hoist` is supported only with `install.nodeLinker: "isolated"` [ERR_NUB_CONFIG_UNSUPPORTED]
```

### `install.minimumReleaseAge`

Reject versions published too recently.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "minimumReleaseAge": "3d"
  }
}
```

Durations use an integer plus one unit.

```text
30s  # seconds
20m  # minutes
12h  # hours
3d   # days
2w   # weeks
```

Exclude selected packages when they must update immediately.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "minimumReleaseAge": "3d",
    "minimumReleaseAgeExclude": [
      "@company/*",
      "typescript"
    ]
  }
}
```

### `install.nodeOptions`

Pass Node options to dependency lifecycle scripts.

```jsonc title="nub.jsonc"
{
  // ...
  "install": {
    "nodeOptions": [
      "--max-old-space-size=8192"
    ]
  }
}
```

## `dlx`

The dlx block configures temporary package runs through `nubx`, `nub dlx`, and `nub x`.

### `dlx.consent`

Ask before an implicit `nubx` registry fetch.

```jsonc title="nub.jsonc"
{
  // ...
  "dlx": {
    "consent": "prompt"
  }
}
```

Disable implicit registry fetches.

```jsonc title="nub.jsonc"
{
  // ...
  "dlx": {
    "consent": "never"
  }
}
```

Explicit `nub dlx` runs still work because the command itself supplies consent.

### `dlx.envFile`

Use a separate environment file for temporary tools.

```jsonc title="nub.jsonc"
{
  // ...
  "dlx": {
    "envFile": "./env/tools.env"
  }
}
```

Disable environment-file loading for temporary tools.

```jsonc title="nub.jsonc"
{
  // ...
  "dlx": {
    "envFile": false
  }
}
```

The field accepts the same boolean, string, and string-array forms as the top-level `envFile` field.
