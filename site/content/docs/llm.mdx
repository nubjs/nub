Run a model on your own machine. The first run downloads the engine and the default model (Qwen3 4B, 2.5 GB).

```console
$ nub llm run "In one sentence, what is a tide pool?"
Provisioning the local-model engine (llama.cpp b10767, Metal backend)…
Downloading model ggml-org/Qwen3-4B-GGUF (Qwen3-4B-Q4_K_M.gguf)…
Tide pools are bodies of seawater left behind in rocky coastal areas when the tide recedes, creating habitats for marine life.
```

## Serving the API

The server binds to `127.0.0.1` and speaks the OpenAI chat-completions API. Set the port with `--port`.

```console
$ nub llm serve
Serving Qwen3-4B-Q4_K_M.gguf at http://127.0.0.1:8012/v1 (OpenAI-compatible) — Ctrl-C stops it.
```

```ts
const res = await fetch("http://127.0.0.1:8012/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    messages: [{ role: "user", content: "Name three tide-pool animals." }],
  }),
});
const { choices } = await res.json();
console.log(choices[0].message.content);
```

## Choosing a model

Pass `--model` to either command with a Hugging Face repository, a quantization, a file name, or a local path.

```sh
nub llm run --model ggml-org/gemma-3-4b-it-GGUF "hello"     # the repo's Q4_K_M file
nub llm run --model ggml-org/Qwen3-4B-GGUF:Q8_0 "hello"     # a quantization
nub llm serve --model ./my-model.gguf                        # a file on disk
nub llm serve --ctx 16384                                    # context window, in tokens
```

## The operating system's model

On macOS 26 and later with Apple Silicon, `--provider os` uses the model that ships with Apple Intelligence. It needs no engine and no download. The context window is 4,096 tokens.

```console
$ nub llm run --provider os "In one sentence, what is a tide pool?"
A tide pool is a small, sheltered area along the shoreline that is exposed during low tide and submerged during high tide, providing a habitat for a variety of marine organisms.
```

Apple Intelligence must be turned on in System Settings. The first use builds a small helper with the Xcode Command Line Tools.

## Engine and platforms

The engine is [llama.cpp](https://github.com/ggml-org/llama.cpp), in the build that uses the operating system's own GPU stack. Nothing ships inside the `nub` binary; the build for your platform (11–35 MB) is fetched on first use.

| Platform | Engine build | Needs |
| --- | --- | --- |
| macOS, Apple Silicon | Metal | macOS 13.3 or later |
| Linux x64 (glibc) | Vulkan | a Vulkan-capable GPU driver |
| Windows x64 | Vulkan | a Vulkan-capable GPU driver |
| Windows arm64 | OpenCL | the Qualcomm Adreno driver |

There is no engine yet for macOS on Intel, Linux arm64, or musl-based Linux.

## Cache

Engines are stored under `~/.cache/nub/llm/engine` and models under `~/.cache/nub/llm/models`. Model files come from Hugging Face and are checked against the SHA-256 the hub publishes. Delete a model file to reclaim its disk.
