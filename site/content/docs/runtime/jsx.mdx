---
title: JSX
description: How Nub runs JSX on stock Node, with automatic-runtime defaults, tsconfig-driven configuration, and a per-file import-source pragma for mixing runtimes.
---

Files ending in `.jsx` and `.tsx` run directly, with the automatic runtime and `react` as the import source by default. Nub parses plain `.js` as JavaScript, so JSX needs a `.jsx` or `.tsx` extension.

```bash
nub render.tsx
```

Preact, Hono, and Vue JSX work through their import source. Solid's JSX needs `babel-preset-solid`'s compiler, which a per-file transpiler cannot run, so run Solid through its bundler (for example `nub run vite`).

## `nub.jsonc`

Configure the runtime in the project file. The field names match TypeScript's compiler options, and `jsx` accepts the three modes that emit executable JavaScript: `react`, `react-jsx`, and `react-jsxdev`.

```jsonc title="nub.jsonc"
{
  "jsx": "react-jsx",
  "jsxImportSource": "preact"
}
```

The classic runtime also takes `jsxFactory` and `jsxFragmentFactory`.

```jsonc title="nub.jsonc"
{
  "jsx": "react",
  "jsxFactory": "h",
  "jsxFragmentFactory": "Fragment"
}
```

## `tsconfig.json`

Nub reads the same options from `compilerOptions` when `nub.jsonc` does not set them. A field set in `nub.jsonc` wins.

| Option | Effect |
| --- | --- |
| `jsx` | The runtime mode: `preserve`, `react`, `react-jsx`, `react-jsxdev`, or `react-native` |
| `jsxImportSource` | The package the automatic runtime imports from, such as `preact` |
| `jsxFactory` | The factory function for the classic runtime |
| `jsxFragmentFactory` | The fragment factory for the classic runtime |

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "preact"
  }
}
```

<Callout>
Read the [full docs](https://www.typescriptlang.org/tsconfig/jsx.html) for `jsx` on typescriptlang.org.
</Callout>

## `@jsxImportSource`

A `/** @jsxImportSource ... */` pragma sets the import source for one file. Use it to mix JSX runtimes in one project, such as a Hono route alongside React components.

```tsx
/** @jsxImportSource hono/jsx */
export default function Page() {
  return <h1>Hello</h1>;
}
```
