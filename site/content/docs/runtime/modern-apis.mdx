Nub fills the gaps between supported Node versions, so the same modern APIs are there whichever Node your project pins. Each entry below says what Nub adds, how it is delivered, and when Node's own implementation takes over.

<TypesSetup>
Nub's types package declares the keyed Promise combinators, `Temporal`, the browser-style `Worker` global, and `reportError`. Standard APIs use TypeScript's bundled libraries and `@types/node`.
</TypesSetup>

## How augmentation works

Nub augments the stock Node binary through mechanisms Node itself provides. It does not patch Node, replace V8, or ship a fork.

- **JavaScript polyfills** run from Nub's preload and feature-detect each property before defining it. They fill missing globals and methods without replacing native or user-supplied implementations.
- **Lazy globals** defer larger fallbacks until first use. On older Node versions, reading `Temporal` loads the fallback and replaces the getter with the resulting namespace.
- **Semantic patches** correct a narrow behavior on versions where an API exists but does not yet match the standard. They are also feature-detected.
- **Experimental flags** expose APIs already built into a particular Node release. Nub derives flags from the exact Node version because passing an unknown flag would abort Node during startup.
- **Loader hooks** add supported import formats through Node's module-loader API. They do not emulate native subsystems that are absent from the running Node.

Native implementations always win. As Node adds an API, Nub's feature check steps aside and the native one takes over.

Compatibility mode turns all of this off: `nub --node`, or `NODE_COMPAT=1`, runs the project's pinned Node with no polyfills, preload patches, loader hooks, or automatically enabled flags. See [the runtime overview](/docs/runtime#compatibility-mode).

Availability below covers Nub's supported Node range, beginning with Node 18.19. A native-version note says when Nub steps aside.

## JavaScript APIs

### `Temporal`

The [`Temporal`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal) namespace provides immutable types for exact instants, calendar values, durations, and time-zone-aware values. An existing `Date` converts through `Date.prototype.toTemporalInstant()`.

<Callout title="Delivery">
Lazy global polyfill on Node 18–25; native on Node 26+. Nub loads `@js-temporal/polyfill` only when code first reads `Temporal` and routes direct imports of that package to the same namespace.
</Callout>

```ts
const deployed = Temporal.Instant.from("2026-08-07T16:30:00Z");
const local = deployed.toZonedDateTimeISO("America/Los_Angeles");
const fromDate = new Date("2026-08-07T16:30:00Z").toTemporalInstant();

console.log(local.add({ days: 1 }).toString());
console.log(fromDate.equals(deployed)); // true
```

### `Promise.allKeyed()`

The keyed Promise combinators accept an object and return a null-prototype object carrying the input's own enumerable string and symbol keys. Values pass through `Promise.resolve`; `allKeyed` rejects on the first rejection, while `allSettledKeyed` records every outcome.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships the [await-dictionary proposal](https://github.com/tc39/proposal-await-dictionary) yet.
</Callout>

```ts
const { account, invoices } = await Promise.allKeyed({
  account: getAccount(accountId),
  invoices: listInvoices(accountId),
});

const outcomes = await Promise.allSettledKeyed({
  profile: getProfile(account.id),
  avatar: getAvatar(account.id),
});
```

### `Promise.withResolvers()`

The [`Promise.withResolvers()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/withResolvers) method creates a promise with its resolve and reject functions. Alongside it, [`Promise.try()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/try) invokes a callback and turns either its return value or thrown error into a promise outcome.

<Callout title="Delivery">
Feature-detected JavaScript polyfills — `Promise.withResolvers()` is native on Node 22+, `Promise.try()` on Node 24+.
</Callout>

```ts
const { promise, resolve } = Promise.withResolvers<string>();
queueMicrotask(() => resolve("ready"));

const config = await Promise.try(() => JSON.parse(source));
console.log(await promise, config);
```

### Iterator helpers

The [iterator helpers](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Iterator) transform and consume iterators lazily without first materializing an array.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 22; native on Node 22+.
</Callout>

```ts
const activeNames = Iterator.from(users)
  .filter((user) => user.active)
  .map((user) => user.name)
  .take(10)
  .toArray();
```

<Callout type="warn" title="Helper identity on older Node">
The fallback returns generator-backed helper objects. Iteration, laziness, validation, and iterator closing match the proposal, but the prototype and `Symbol.toStringTag` differ from native iterator-helper objects.
</Callout>

The supplied helpers are:

```text
map  filter  take  drop  flatMap  reduce  toArray  some  every  find  forEach
```

### `Iterator.concat()`

The [`Iterator.concat()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Iterator/concat) method lazily visits each iterable in sequence.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 26; native on Node 26+.
</Callout>

```ts
const allIds = Iterator.concat(primaryIds, archivedIds).toArray();
```

### `Iterator.zip()`

The [joint-iteration methods](https://github.com/tc39/proposal-joint-iteration) advance several iterables together: `zip()` yields arrays, and `zipKeyed()` preserves the keys of an input object.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships these methods yet.
</Callout>

```ts
const pairs = Iterator.zip([ids, names]).toArray();

for (const row of Iterator.zipKeyed({ id: ids, name: names })) {
  console.log(row.id, row.name);
}
```

### `Iterator.prototype.chunks()`

These helpers [batch an iterator](https://github.com/tc39/proposal-iterator-chunking), produce overlapping windows, search for a value, or join values into a string.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships these methods yet.
</Callout>

```ts
const batches = Iterator.from(records).chunks(100).toArray();
const movingTriples = Iterator.from(values).windows(3).toArray();
const hasDraft = Iterator.from(statuses).includes("draft");
const label = Iterator.from(tags).join(", ");
```

### `Set.prototype.union()`

The [Set methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) provide standard union, intersection, difference, relationship, and overlap operations.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 22; native on Node 22+.
</Callout>

```ts
const visible = owned.union(shared).difference(hidden);
const overlap = selected.intersection(available);

if (required.isSubsetOf(visible) && blocked.isDisjointFrom(visible)) {
  render(visible);
}
```

The complete family is:

```text
union  intersection  difference  symmetricDifference
isSubsetOf  isSupersetOf  isDisjointFrom
```

### `Map.prototype.getOrInsert()`

The [insertion methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/getOrInsert) return an existing value or insert one when the key is absent. The computed form calls its callback only for a missing key. Both methods are also available on `WeakMap`.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 26; native on Node 26+.
</Callout>

```ts
const cache = new Map<string, Result>();
const result = cache.getOrInsertComputed(key, () => calculate(key));
```

### `Object.groupBy()`

The [grouping methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/groupBy) partition an iterable by a key returned from a callback.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 21; native on Node 21+.
</Callout>

```ts
const byStatus = Object.groupBy(tasks, (task) => task.status);
const byOwner = Map.groupBy(tasks, (task) => task.owner);
```

### `Array.prototype.toSorted()`

The [copying methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/toSorted) produce an updated array without mutating the original. Typed arrays support `toSorted`, `toReversed`, and `with`, but not `toSpliced`.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 20; native on Node 20+.
</Callout>

```ts
const ranked = scores.toSorted((a, b) => b - a);
const corrected = values.with(2, replacement);
const withoutFirst = values.toSpliced(0, 1);
const reversed = values.toReversed();
```

### `String.prototype.isWellFormed()`

These methods [detect or replace lone UTF-16 surrogates](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/isWellFormed).

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 20; native on Node 20+.
</Callout>

```ts
if (!input.isWellFormed()) {
  input = input.toWellFormed();
}
```

### `ArrayBuffer.prototype.transfer()`

The [transfer methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer/transfer) move an ArrayBuffer's bytes into a new buffer and detach the original.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 21; native on Node 21+.
</Callout>

```ts
const source = new ArrayBuffer(1024);
const resized = source.transfer(2048);

console.log(source.detached); // true
console.log(resized.byteLength); // 2048
```

### `Array.fromAsync()`

The [`Array.fromAsync()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/fromAsync) method builds an array from an async iterable, optionally mapping each value as it arrives.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 22; native on Node 22+.
</Callout>

```ts
const rows = await Array.fromAsync(stream, (row) => normalize(row));
```

### `URL.parse()`

The [`URL.parse()`](https://developer.mozilla.org/en-US/docs/Web/API/URL/parse_static) method returns a parsed URL, or `null` where the `URL` constructor would throw.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on Node versions without the method. It is native on Node 20.19–20.x and Node 22.1+.
</Callout>

```ts
const callback = URL.parse(value, "https://example.com");
if (callback) console.log(callback.pathname);
```

### `RegExp.escape()`

The [`RegExp.escape()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/escape) method quotes a string for literal use inside a regular expression.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 24; native on Node 24+.
</Callout>

```ts
const exactName = new RegExp(`^${RegExp.escape(name)}$`, "u");
```

### `Error.isError()`

The [`Error.isError()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/isError) method identifies Error objects without relying on a mutable prototype property.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 24; native on Node 24+.
</Callout>

```ts
try {
  await runTask();
} catch (error) {
  if (Error.isError(error)) console.error(error.message);
}
```

<Callout type="warn" title="Cross-realm errors on older Node">
On Node 23 and below, the userland fallback cannot recognize an Error created in another realm because V8's internal Error slot is not exposed to JavaScript.
</Callout>

### `Float16Array`

The [half-precision float APIs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Float16Array) store and round IEEE 754 binary16 values.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 24; native on Node 24+.
</Callout>

```ts
const samples = new Float16Array([0.1, 0.2, 0.3]);
const rounded = Math.f16round(1 / 3);

const view = new DataView(new ArrayBuffer(2));
view.setFloat16(0, rounded);
console.log(view.getFloat16(0));
```

<Callout type="warn" title="ArrayBuffer views on older Node">
On Node 23 and below, `ArrayBuffer.isView()` cannot recognize a polyfilled `Float16Array` because JavaScript cannot create V8's internal typed-array slot.
</Callout>

### `Uint8Array.prototype.toBase64()`

The [encoding methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array/toBase64) convert bytes to and from base64, base64url, and hexadecimal text. The `setFrom` variants decode into an existing array and report how much input was read and how many bytes were written.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 25; native on Node 25+.
</Callout>

```ts
const bytes = new TextEncoder().encode("hello");
const encoded = bytes.toBase64({ alphabet: "base64url", omitPadding: true });
const decoded = Uint8Array.fromBase64(encoded, { alphabet: "base64url" });

console.log(decoded.toHex());
```

The complete family is:

```text
toBase64  fromBase64  setFromBase64  toHex  fromHex  setFromHex
```

### `DisposableStack`

A [`DisposableStack`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/DisposableStack) collects cleanup callbacks and disposable resources, then releases them in reverse order.

<Callout title="Delivery">
Feature-detected JavaScript polyfill before Node 24; native on Node 24+.
</Callout>

```ts
const stack = new DisposableStack();
stack.defer(() => releaseLock());
stack.adopt(openHandle(), (handle) => handle.close());

try {
  await work();
} finally {
  stack.dispose();
}
```

### `Math.sumPrecise()`

The [`Math.sumPrecise()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/sumPrecise) method reduces floating-point error and avoids overflow caused only by an unfortunate addition order.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships this method yet.
</Callout>

```ts
const total = Math.sumPrecise([1, 1e100, 1, -1e100]);
console.log(total); // 2
```

### `Symbol.metadata`

Decorators use [`Symbol.metadata`](https://github.com/tc39/proposal-decorator-metadata) as the key for class metadata.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships this symbol yet.
</Callout>

```ts
const metadata = Example[Symbol.metadata];
```

### `Atomics.pause()`

The [`Atomics.pause()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Atomics/pause) method provides a hint inside short spin-wait loops.

<Callout title="Delivery">
Feature-detected JavaScript polyfill on every supported Node version. No Node release ships this method yet; the fallback validates its argument and otherwise acts as a no-op.
</Callout>

```ts
while (Atomics.load(state, 0) === 0) {
  Atomics.pause();
}
```

## Web APIs

### `URLPattern`

A [`URLPattern`](https://developer.mozilla.org/en-US/docs/Web/API/URLPattern) matches URL components and exposes named groups.

<Callout title="Delivery">
Feature-detected global polyfill before Node 24; native on Node 24+.
</Callout>

```ts
const route = new URLPattern({ pathname: "/users/:id" });
const match = route.exec("https://example.com/users/42");
console.log(match?.pathname.groups.id); // 42
```

### `File`

A [`File`](https://developer.mozilla.org/en-US/docs/Web/API/File) represents named Blob data with a media type and modification time.

<Callout title="Delivery">
Feature-detected global polyfill on Node 18 and 19; native on Node 20+.
</Callout>

```ts
const file = new File([JSON.stringify(payload)], "payload.json", {
  type: "application/json",
});
```

### `navigator`

The global [`navigator`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator) exposes server-relevant runtime information such as `hardwareConcurrency` and `userAgent`.

<Callout title="Delivery">
Feature-detected global shim before Node 21; native on Node 21+. Nub adds only missing properties and preserves any existing navigator object.
</Callout>

```ts
const workers = Math.max(1, navigator.hardwareConcurrency - 1);
console.log(navigator.userAgent, workers);
```

### `navigator.locks`

The [Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API) coordinates asynchronous access to a named resource within the process.

<Callout title="Delivery">
Feature-detected Web Locks implementation before Node 24.5; native on Node 24.5+.
</Callout>

```ts
await navigator.locks.request("database-migration", async () => {
  await migrate();
});
```

### `Worker`

Nub exposes a browser-style [`Worker`](https://developer.mozilla.org/en-US/docs/Web/API/Worker) global backed by Node worker threads, including web events, message channels, transfer lists, TypeScript entrypoints, and worker names.

<Callout title="Delivery">
Preload-installed global on every supported Node version. Node does not ship a browser-style global Worker; Nub adapts `node:worker_threads` without replacing that module.
</Callout>

```ts
const worker = new Worker(new URL("./worker.ts", import.meta.url), {
  name: "thumbnailer",
});

worker.onmessage = ({ data }) => console.log(data);
worker.postMessage({ source: "photo.jpg" });
```

See [Web Workers](/docs/runtime/workers) for lifecycle events, worker options, module loading, and Node interop.

### `localStorage`

The [storage globals](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API) provide synchronous string key/value storage using Node's built-in Web Storage implementation.

<Callout title="Delivery">
Version-gated Node API available on Node 22.4+. Nub enables the experimental flag before Node 25, but a storage file is still required; Nub does not emulate the API on older Node.
</Callout>

```ts
localStorage.setItem("theme", "dark");
const theme = localStorage.getItem("theme");

sessionStorage.setItem("request-id", crypto.randomUUID());
```

See [Web Storage](/docs/runtime/web-storage) for configuring the storage file and choosing a scope.

### `reportError()`

The [`reportError()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/reportError) function reports an exception through the host's uncaught-error path without throwing it at the call site.

<Callout title="Delivery">
Feature-detected global polyfill on every supported Node version. No Node release ships this global yet.
</Callout>

```ts
backgroundTask().catch((error) => {
  reportError(error);
});
```

### `WebSocket`

The [`WebSocket`](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket) global creates standards-compatible client connections.

<Callout title="Delivery">
Version-gated Node API available on Node 20.10+. Nub enables Node's experimental implementation before Node 22; it is native without a flag on Node 22+. Nub does not emulate it on earlier releases.
</Callout>

```ts
const socket = new WebSocket("wss://example.com/events");
socket.addEventListener("message", ({ data }) => console.log(data));
```

### `EventSource`

An [`EventSource`](https://developer.mozilla.org/en-US/docs/Web/API/EventSource) consumes a server-sent event stream.

<Callout title="Delivery">
Version-gated Node API available on Node 20.18–20.x and Node 22.3+. It is unavailable on Node 21 and remains experimental through Node 26.
</Callout>

```ts
const events = new EventSource("https://example.com/events");
events.addEventListener("update", ({ data }) => console.log(data));
```

### `MessageEvent.ports`

Transferred message ports are exposed through a read-only [`ports`](https://developer.mozilla.org/en-US/docs/Web/API/MessageEvent/ports) array, matching the web-platform contract.

<Callout title="Delivery">
Semantic preload patch on older Node versions whose `MessageEvent.ports` value is mutable. Nub leaves conforming native behavior unchanged.
</Callout>

```ts
channel.port1.onmessage = (event) => {
  const [transferredPort] = event.ports;
  transferredPort?.postMessage("received");
};
```

## Node.js APIs and loading behavior

These entries expose parsers, modules, and flags already present in particular Node releases. Nub does not polyfill a missing native subsystem.

### `vm.Module`

The [VM module classes](https://nodejs.org/api/vm.html#class-vmmodule) compile and link ECMAScript modules inside a VM context.

<Callout title="Delivery">
Experimental-flag enablement on every supported Node version. Nub passes `--experimental-vm-modules` automatically.
</Callout>

```ts
import vm from "node:vm";

const module = new vm.SourceTextModule("export const answer = 42");
await module.link(() => { throw new Error("no imports expected"); });
await module.evaluate();
```

### WebAssembly module imports

WebAssembly modules can be imported through [the ESM loader](https://nodejs.org/api/esm.html#wasm-modules).

<Callout title="Delivery">
Node feature enabled automatically across the supported range. Nub passes the experimental flag on Node 18.19–22.18 and 23.0–24.4; the feature is unflagged on Node 22.19–22.x and Node 24.5+.
</Callout>

```ts
import { add } from "./math.wasm";

console.log(add(20, 22));
```

### `node:sqlite`

Node's built-in [SQLite module](https://nodejs.org/api/sqlite.html) provides synchronous database access without an npm dependency.

<Callout title="Delivery">
Version-gated Node API available on Node 22.5+. Nub enables its experimental flag before Node 22.13 and 23.4; it is unflagged afterward.
</Callout>

```ts
import { DatabaseSync } from "node:sqlite";

const database = new DatabaseSync("app.db");
const row = database.prepare("SELECT count(*) AS count FROM users").get();
```

### Native addon imports

Native `.node` addons can be imported directly from an ES module.

<Callout title="Delivery">
Version-gated Node API available on Node 22.20–22.x and Node 23.6+. Nub enables [`--experimental-addon-modules`](https://nodejs.org/api/cli.html#--experimental-addon-modules); the feature remains experimental through Node 27.
</Callout>

```ts
import addon from "./build/Release/addon.node";

console.log(addon.version());
```

### Text imports

The `type: "text"` import attribute loads a file as a string, the shape Node calls [text modules](https://nodejs.org/api/esm.html#text-modules).

<Callout title="Delivery">
Loader-hook fallback from Node 18.20 onward, or Node's flagged implementation on Node 24.19–24.x and 26.5+. Nub uses the native parser where available.
</Callout>

```ts
import template from "./email.html" with { type: "text" };

console.log(template.length);
```

### `node:stream/iter`

The [stream iterator module](https://nodejs.org/api/stream_iter.html) provides iterator-oriented stream utilities.

<Callout title="Delivery">
Version-gated Node API available on Node 25.9+. Nub enables `--experimental-stream-iter`; it does not emulate the module on older releases.
</Callout>

```ts
import { from, text } from "node:stream/iter";

const source = from("Hello, world!");
console.log(await text(source));
```

### `node:ffi`

The [FFI module](https://nodejs.org/api/ffi.html) calls functions in native dynamic libraries.

<Callout title="Delivery">
Version-gated Node API available on Node 26.1+. Nub enables `--experimental-ffi`; permission flags remain the application's choice.
</Callout>

```ts
import { dlopen } from "node:ffi";

const { lib, functions } = dlopen("./libmath.so", {
  add_i32: { arguments: ["i32", "i32"], return: "i32" },
});

console.log(functions.add_i32(20, 22));
lib.close();
```

### `node:vfs`

The [VFS module](https://nodejs.org/api/vfs.html) exposes Node's virtual filesystem primitives.

<Callout title="Delivery">
Version-gated Node API available on Node 26.4+. Nub enables `--experimental-vfs`; it does not emulate the module on older releases.
</Callout>

```ts
import vfs from "node:vfs";

const memory = vfs.create();
memory.mkdirSync("/data", { recursive: true });
memory.writeFileSync("/data/message.txt", "hello");
console.log(memory.readFileSync("/data/message.txt", "utf8"));
```

### Deferred module evaluation

The [`import defer`](https://github.com/tc39/proposal-defer-import-eval) form resolves and links a module without running it. Evaluation happens on the first property access of the namespace.

<Callout title="Delivery">
Version-gated V8 feature available on Node 26.4+. Nub passes `--js-defer-import-eval` on the command line, since Node rejects that flag in `NODE_OPTIONS`. A subprocess launched as `node` inherits it through Nub's shim; one launched by absolute executable path does not.
</Callout>

```ts
import defer * as analytics from "./analytics.ts";

// Nothing in analytics.ts has run yet.
if (consented) {
  analytics.track("start"); // the module evaluates here, once
}
```

<Callout type="warn" title="The dynamic form aborts the process">
Nub enables this V8 feature for every program on Node 26.4+, not only the ones that use it. So the dynamic counterpart, `import.defer(specifier)`, behaves differently than it does on bare Node: Node raises a catchable `SyntaxError`, while under Nub the same code dies on a V8 fatal error that no handler can catch. The underlying crash is a Node defect, but Nub is what exposes it. Use the static form.
</Callout>

### Module syntax detection

[Syntax detection](https://nodejs.org/api/packages.html#syntax-detection) lets Node classify ambiguous `.js` input as ESM when it contains module syntax.

<Callout title="Delivery">
Version-gated Node behavior available on Node 20.10+ except Node 21.0. Nub enables the flag before it became default in Node 20.19 and 22.7.
</Callout>

```js
// package.json has no "type" field; Node detects this file as ESM.
export const answer = 42;
```
